# Logos officiels des actifs

Déposer ici trois fichiers PNG carrés, fond transparent, 256 px minimum :

    btc.png
    eth.png
    sol.png

`CryptoLogo` les utilise dès qu'ils existent. Tant qu'un fichier est absent, le
tracé vectoriel actuel est conservé : l'app ne montre jamais un carré vide à la
place d'un logo, et n'a pas besoin des fichiers pour compiler.

Le nom du fichier est le symbole en minuscules, ce qui rend l'ajout d'un actif
supplémentaire immédiat.
